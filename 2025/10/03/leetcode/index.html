leetcode11 盛最多水的容器

给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。
示例 1：
输入：[1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。
示例 2：

输入：height = [1,1]
输出：1

总结

双指针解法的要点：指针每一次移动，都意味着排除掉了一个柱子。

如果选择固定一根柱子，另外一根变化，水的面积会有什么变化吗？稍加思考可得：

  • 当前柱子是最两侧的柱子，水的宽度 d 为最大，其他的组合，水的宽度都比这个小。
  • 左边柱子较短，决定了水的高度为 3。如果移动左边的柱子，新的水面高度不确定，一定不会超过右边的柱子高度 7。
  • 如果移动右边的柱子，新的水面高度一定不会超过左边的柱子高度 3，也就是不会超过现在的水面高度。
    由此可见，如果固定左边的柱子，移动右边的柱子，那么水的高度一定不会增加，且宽度一定减少，所以水的面积一定减少。这个时候，左边的柱子和任意一个其他柱子的组合，其实都可以排除了。也就是我们可以排除掉左边的柱子了。
    这个排除掉左边柱子的操作，就是双指针代码里的 i++。i 和 j 两个指针中间的区域都是还未排除掉的区域。随着不断的排除，i 和 j 都会往中间移动。当 i 和 j 相遇，算法就结束了。

leetcode15 三数之和

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

示例 1：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。
示例 2：

输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。

总结

  • 最直接的办法是暴力解法，三重循环，时间复杂度是 O(n^3)，空间复杂度是 O(1)。
  • 使用排序下 + 双指针，时间复杂度是 O(n^2)，空间复杂度是 O(1)。
    • 首先对数组排序 nums.sort()
    • 其次还是遍历，从 0 到 len(nums)-2，因为需要三个数，所以 i 不能到 len(nums)-1
    • 如果 i > 0 且 nums[i] == nums[i-1]，则跳过，因为已经遍历过这个数了
    • 定义 left 和 right 指针，分别指向 i+1 和 len(nums)-1
      • 如果 total == 0，则将 nums[i], nums[left], nums[right] 加入 res，并且 left += 1，right -= 1，因为已经找到一个解了，所以需要继续找下一个解
      • 如果 total < 0，则 left += 1
      • 如果 total > 0，则 right -= 1
    • 最后返回 res

给你一个长度为 n 的整数数组 nums 和 一个目标值 target。请你从 nums 中选出三个整数，使它们的和与 target 最接近。

  • 使用排序下 + 双指针，时间复杂度是 O(n^2)，空间复杂度是 O(1)。
  • 首先对数组排序 nums.sort()
  • 其次还是遍历，从 0 到 len(nums)-2，因为需要三个数，所以 i 不能到 len(nums)-1
  • 如果 i > 0 且 nums[i] == nums[i-1]，则跳过，因为已经遍历过这个数了
  • 定义 left 和 right 指针，分别指向 i+1 和 len(nums)-1
    • 如果 total == target，则返回 total
    • 如果 total < target，则 left += 1
    • 如果 total > target，则 right -= 1
  • 最后返回 res

    • fast 走到 None，slow 距离 fast（None） 为 n+2，正好为倒数 n+1，正好是我们要删除的节点
  • 删除倒数第 n 个节点

回溯

回溯算法本质上是一种通过​​深度优先搜索（DFS）​​ 来尝试所有可能解的策略。它通过“选择 -> 递归 -> 撤销选择”（即​​回溯​​）的步骤，系统地遍历整个解空间（通常抽象为一棵​​决策树​​），并在遍历过程中通过​​剪枝​​来避免无效的搜索。
其通用模板如下，绝大多数回溯问题都是这个框架的变形

  1. 组合问题 (Combination)
    核心在于​​顺序无关​​，[1,2]和 [2,1]被视为同一个组合。
    ​​startIndex是关键​​：它确保了每次选择都从当前元素之后开始，避免了产生重复的组合。
    ​​元素可重复使用 (如39题)​​：递归时传递的起始位置是 i而不是 i+1，允许下一次选择再次包含当前元素。
    ​​树层去重 (如40题)​​：当原集合有重复元素时，需要避免在同一层递归中选择值相同的元素。通常先​​排序​​，然后判断 if (i > startIndex && candidates[i] == candidates[i-1]) continue;

  2. 排列问题 (Permutation)
    核心在于​​顺序相关​​，[1,2]和 [2,1]是两个不同的排列。
    ​​used数组是核心​​：记录哪些元素已经在当前路径中被使用过，确保每个元素在一条路径中只被使用一次

​​排列去重 (如47题)​​：同样需要先排序。去重的关键条件是：if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;。这里的 !used[i-1]表示前一个相同元素刚刚在回溯中被撤销选择，说明当前是在同一树层，需要跳过以避免重复

  1. 子集问题 (Subset)
    子集问题可以看作是收集决策树上​​所有节点​​（而不仅仅是叶子节点）的结果。
    ​​无重子集 (如78题)​​：在回溯函数的一开始就将当前路径加入结果集

​​子集去重 (如90题)​​：去重思路与组合问题的树层去重完全一致

  1. 切割问题 (Partition)
    这类问题可以转化为​​组合问题​​，将切割点视为选择

​​核心步骤​​：用 startIndex模拟切割的起始位置，在 [startIndex, i]区间内判断当前子串是否合法（如是否是回文串、是否符合IP地址段规则），合法则继续递归切割剩余部分 [i+1, …]

  1. 棋盘问题 (Board)
    这是回溯算法中约束条件最复杂的一类问题。
    ​​N皇后 (51题)​​：逐行放置皇后。关键是如何高效判断当前位置是否会被已放置的皇后攻击（列、左上对角线、右上对角线）。可以使用集合或数组来记录已被占用的列和对角线

​​解数独 (37题)​​：遍历每一个空格，尝试填入1-9的数字。需要一个高效的 isValid函数来检查当前数字在行、列、3x3宫内的唯一性。解数独通常使用返回布尔值的回溯函数，因为找到一组解即可返回

​​基础入门​​：从 ​​77. 组合​​ 和 ​​78. 子集​​ 开始，理解 startIndex和回溯模板。
​​掌握去重​​：攻克 ​​40. 组合总和II​​ 和 ​​90. 子集II​​，彻底理解​​树层去重​​。
​​理解排列​​：练习 ​​46. 全排列​​ 和 ​​47. 全排列II​​，掌握 used数组和排列去重。
​​挑战应用​​：尝试 ​​131. 分割回文串​​ 和 ​​93. 复原IP地址​​，将回溯应用于复杂场景。
​​攀登高峰​​：最后集中精力解决 ​​51. N皇后​​ 和 ​​37. 解数独​​，锻炼处理复杂约束的能力。

leetcode77 组合

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

你可以按 任何顺序 返回答案。

示例 1：

输入：n = 4, k = 2
输出：
[[2,4],[3,4],[2,3],[1,2],[1,3],[1,4],]

总结：

  • 使用 dfs 来解决这个问题，dfs 的参数是 start_index，表示从哪个数开始选
  • 使用 result 来存储结果，使用 combination 来存储当前的组合
  • 使用 combination.copy() 来存储当前的组合，因为使用 result.append(combination) 会存储的是列表 combination 的引用，在后续的回溯中（combination.pop()），会不断地修改这个列表对象本身。由于 result 里存放的都是对同一个列表的引用，当递归结束时，combination 被清空，result 中所有的引用自然也指向了空列表

leetcode78 子集

给你一个整数数组 nums ，数组中的元素 互不相同 。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

示例 1：

输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

总结：

  • 使用 dfs 来解决这个问题，dfs 的参数是 start_index，表示从哪个数开始选
  • 使用 result 来存储结果，使用 subset 来存储当前的子集
  • 使用 result.append([]) 来添加空子集
  • 使用 dfs(0) 来开始递归
  • 使用 subset.append(nums[i]) 来添加当前的数
  • 使用 dfs(i+1) 来递归
  • 使用 result.append(subset[:]) 来添加当前的子集
  • 使用 subset.pop() 来回溯

leetcode40 组合总和 II

给定一个候选人编号的集合 candidates 和一个目标数 target ，找出 candidates 中所有和为 target 的组合。
candidates 中的每个数字在每个组合中只能使用 一次 。
注意：解集不能包含重复的组合。

示例 1:
输入: candidates = [10,1,2,7,6,1,5], target = 8,
输出:
[[1,1,6],[1,2,5],[1,7],[2,6]]

总结：

第40题去重的关键在于理解​​树层去重​​与​​树枝去重​​的区别

  • ​树层去重​​：在​​同一层递归的循环中​​，如果当前元素与前一个元素相同，则跳过，避免产生重复的组合。
  • ​​树枝去重​​：在​​同一条递归路径（树枝）上​​，允许使用值相同的元素，因为它们处于路径的不同位置。
    以示例 candidates = [2,5,2,1,2], target = 5为例，排序后为 [1,2,2,2,5]。在树层去重中，当第一个2被使用后，同一层中后续的2都会被跳过，从而避免产生多个[1,2,2]这样的重复组合。但在树枝上，路径[2] -> [2,2]是允许的，因为这是深度递归过程中元素的不同次使用
